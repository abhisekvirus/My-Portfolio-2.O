# Abhisek Maharana — Portfolio

A responsive static portfolio built with HTML, CSS, and vanilla JavaScript. It is ready for Vercel static deployment.

## Files
- `index.html` — page content and sections
- `css/style.css` — layout, responsive styles, visual design
- `js/script.js` — mobile navigation and current footer year
- `assets/Abhisek-Maharana-Resume.pdf` — resume download

## Run locally
Open `index.html` in your browser, or use VS Code's Live Server extension.

## Deploy to Vercel
1. Upload/push the contents of this folder to a GitHub repository.
2. In Vercel, choose **Add New → Project** and import that repository (or open your existing Vercel project and connect the updated repository).
3. Framework preset: **Other**.
4. Build command: leave blank.
5. Output directory: `.` (root).
6. Deploy. To update an existing deployment, push a commit to the connected production branch.
